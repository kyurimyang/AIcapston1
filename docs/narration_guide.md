# 해설 작성 원칙과 검수

해설 원문: `backend/scripts/narrations.json` (2점 × 3프로필 × 2길이 = 12개)
`/narration`은 `reviewed: true`인 해설만 내보낸다. 검수 전에는 404가 난다.

## 근거
- 사실은 `backend/scripts/artifact_meta.json`의 국가유산포털 설명에 있는 것만 쓴다.
- 원문에 없는 색·재질감·전시 위치·크기 비교는 넣지 않는다. 예외: 높이를 몸으로 느끼게 하는 일상 비교(“책상보다 조금 높은”)와 금동의 뜻(청동에 금을 입힘).

## 공통
- TTS로 읽히므로 괄호·한자·기호를 쓰지 않는다. `cm` → “센티미터”, `제78호` → “78호”.
- 첫 문장에 국보 번호와 이름을 말한다. 두 점의 이름이 같으므로 번호가 식별 정보다.
- 두 점을 가르는 특징을 반드시 넣는다.
  - 78호: 화려한 관, 손가락을 **뺨**에 댐, 두툼한 치마
  - 83호: 둥근 산 세 개 모양 관(삼산관), 손가락으로 **턱**을 굄, 윗몸에 옷 없이 두 줄 목걸이, 왼손이 오른 발목을 잡음
- 길이: 짧게 약 30초(150~180자), 자세히 약 1분 30초(500~650자). TTS 1.0배속 기준.

## 프로필별
| 프로필 | 원칙 |
|---|---|
| 선천 전맹 `congenital` | 시각 기억을 전제하지 않는다. 자세는 듣는 사람이 직접 따라 할 수 있게 몸 동작으로 안내하고, 모양은 손으로 느낄 수 있는 말(둥글고 길쭉한, 도톰한, 겹겹이)로 옮긴다. “미소”는 얼굴 근육의 모양으로 풀어 쓴다. |
| 후천 전맹 `acquired` | 시각 기억을 활용한다. “떠올려 보세요”로 장면을 그리게 하고, 원문의 시각적 비유(새의 깃털처럼, 우아한 곡선)를 살린다. |
| 저시력 `low_vision` | 남은 시력으로 찾아볼 수 있게 위에서 아래 순서로 부위를 짚는다. 찾기 쉬운 기준점(손이 닿은 곳 바로 위가 얼굴)을 준다. |

## 검수 체크리스트 (항목마다)
- [ ] 모든 사실이 `artifact_meta.json` 원문과 맞는가 (특히 좌우: 올린 발은 오른발, 내린 발은 왼발)
- [ ] 78호/83호 구분 특징이 들어갔는가
- [ ] 실제 TTS(안드로이드 크롬, ko-KR)로 들어 봤을 때 어색하게 읽히는 단어가 없는가
- [ ] 길이가 목표 시간 안인가
- [ ] 통과하면 `"reviewed": true`로 바꾼다
