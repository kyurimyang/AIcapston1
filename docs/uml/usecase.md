다이어그램: `usecase.png` (원본 `usecase.svg`, 편집용 `usecase.puml`)

## 액터
| 액터 | 설명 |
|---|---|
| 시각장애 관람객 | 주 사용자. 시각 경험에 따라 선천 전맹·후천 전맹·저시력으로 나뉘며, 셋은 같은 기능을 쓰되 해설 내용이 다르다 (일반화) |
| LLM 서비스 | 외부 시스템. 추가 질문 답변과 해설 초안 생성에 쓰인다 |
| 운영팀 | 시연 준비 단계에서 유물 정보·해설·인식 모델을 마련한다 |

## 주요 유스케이스

### UC1 프로필·해설 길이 설정
- 액터: 시각장애 관람객
- 기본 흐름: 앱 실행 → 음성 안내 → 시각 경험(선천 전맹/후천 전맹/저시력) 선택 → 해설 길이(짧게/자세히) 선택 → 기기에 저장
- 사후 조건: 다음 실행부터는 이 단계를 건너뛴다. 촬영 화면에서 다시 바꿀 수 있다

### UC2 유물 촬영 (include: 유물 식별)
- 액터: 시각장애 관람객
- 사전 조건: 프로필 설정 완료, HTTPS 접속
- 기본 흐름: 카메라 미리보기 → 화면 아래 절반을 눌러 촬영(진동) → "확인하고 있어요" 안내 → 사진 축소 후 서버 전송 → 유물 식별 → 식별 성공이면 UC4로
- 확장 (사진 올리기): 카메라를 쓸 수 없으면 사진을 골라 올린다

### UC3 유물 식별 (extend: 재촬영 안내 받기)
- 기본 흐름: CLIP 임베딩 → FAISS에서 유물별 최고 유사도 → 1위 점수 ≥ T 이고 1·2위 차이 ≥ M이면 식별 성공
- 확장 (재촬영 안내): 1·2위가 비슷하면 "반가사유상 종류로 보여요. 조금 더 가까이에서 다시 찍어 주세요", 점수 < T면 "유물을 찾지 못했어요. 정면에서 다시 찍어 주세요"

### UC4 맞춤 해설 듣기 (extend: 해설 속도 조절)
- 액터: 시각장애 관람객
- 기본 흐름: 식별된 유물 × 프로필 × 길이에 맞는 검수 완료 해설을 불러와 바로 음성 재생 → 다시 듣기 가능
- 확장 (속도 조절): 느리게/보통/빠르게를 고르면 그 속도로 처음부터 다시 읽는다
- 규칙: 검수(reviewed)되지 않은 해설은 내보내지 않는다

### UC5 추가 질문하기 (include: 근거 기반 답변 듣기)
- 액터: 시각장애 관람객, LLM 서비스
- 기본 흐름: 질문 버튼 → "말씀하세요" 안내 → 음성 인식 → 질문을 다시 읽어 줌 → 유물 설명을 근거로 LLM이 답변 → 답변 음성 재생
- 확장 (글로 질문하기): 음성 인식을 쓸 수 없으면 입력창에 적는다
- 규칙: 근거 자료에 없는 내용이면 "자료에 없는 내용이에요"라고 답한다

### 운영 유스케이스 (시연 준비)
| 유스케이스 | 내용 |
|---|---|
| 해설 생성·검수 | 국가유산포털 원문만 근거로 2점 × 3프로필 × 2길이 = 12개 작성, 사람이 검수 후 공개 (`docs/narration_guide.md`) |
| 유물 정보 등록 | 유물 이름·시대·재질·크기·설명·출처·라이선스를 DB에 등록 |
| 인식 모델 학습·임계값 설정 | K-Art로 파인튜닝, val·유물 없는 사진으로 T·M 결정 (test는 평가에만) |
